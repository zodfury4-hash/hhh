# Organizing Links with Tags and Campaign Names

As your link library grows, organizing links into intuitive operational groups helps you maintain clarity and evaluate marketing channel performance.

## Adding Tags to Links

1. Open any link in the **Links** pane (`#links`).
2. In the link editing view, enter a tag name (e.g. `newsletter`, `affiliate`, `q4-promo`).
3. You can attach multiple tags to a single link for granular filtering.

## Grouping Links by Campaign

When building trackable links using the **UTM Campaign Builder**, attaching a campaign parameter (e.g. `summer-promo-2026`) automatically groups those links within the **Campaigns** dashboard view.

## Filtering and Searching Your Library

- **Search Bar:** Type keywords matching the title, custom slug, destination URL, or tag.
- **Tag Filtering:** Click any tag badge to isolate links matching that tag across all views.
- **Exporting by Tag:** When exporting data to CSV or JSON, you can filter by specific campaign or tag filters.
