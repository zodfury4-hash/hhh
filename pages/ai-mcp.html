Available MCP Tools

Tool Name Description Required Scope Key Parameters
hea_list_links List caller's short links with pagination and optional tag filtering. links:read limit (number), offset (number), tag (string)
hea_get_link Fetch destination, click statistics, tags, and security settings for a link by slug. links:read slug (string, required)
hea_create_link Create a branded short link with optional custom slug, passcode, or expiration. links:write dest (required), slug, title, tag, password, expiresAt
hea_update_link Update destination URL, title, tags, or expiration on an existing link. links:write slug (required), dest, title, tag, password, expiresAt
hea_delete_link Permanently delete an owned short link from the user's account. links:write slug (required)
hea_get_analytics Retrieve real-world click counts, unique visitors, top countries, and referrers. analytics:read range ('24h'|'7d'|'30d'|'90d'), slug (optional)
hea_generate_slugs Semantic AI slug generator delivering available candidates for a destination URL. links:read url (required), tone ('brand'|'creative'|'short'|'seo'), count
hea_create_qr Generate high-resolution PNG and SVG QR codes for an owned link. links:read slug (required), size (number)

Frequently Asked Questions

What is Model Context Protocol (MCP)?

MCP is an open standard developed by Anthropic that enables AI assistants (like Claude, Cursor, and autonomous agents) to safely interact with developer tools and data stores through standardized JSON-RPC.

Can another user see my links or analytics?

No. Every MCP call is strictly authenticated against your Personal Access Token. Read and write operations are tenant-isolated to your account email with zero cross-tenant visibility.

Are passwords and passcodes logged?

No. The built-in MCP audit logger automatically scrubs sensitive parameters like passwords, passcodes, and raw tokens before writing audit records.

Can I run the MCP server over stdio locally?

Yes. You can run npx hea-link-mcp locally in your command-line or Claude Desktop configuration. It automatically talks to your running instance via stdio transport.
