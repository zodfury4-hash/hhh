🚀 Quickstart

Start shortening links in under 60 seconds with our official REST endpoints. You'll need an active API key to authenticate.

  1. Generate an API Key: Visit Dashboard > API Keys or make a request to POST /api/keys to create a key with links:write and links:read scopes. Use hea_test_... for staging/CI environments and hea_live_... for production.
  2. Send Your First Request: Pass your secret key in the Authorization: Bearer <key> or X-API-Key: <key> header.
curl -X POST https://hea.link/api/v1/links \
  -H "Authorization: Bearer hea_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "dest": "https://store.yourbrand.com/products/summer26",
    "title": "Summer Campaign",
    "tags": ["summer", "promo"]
  }'
// Node.js 18+ native fetch
const res = await fetch('https://hea.link/api/v1/links', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer ' + process.env.HEA_API_KEY,
    'Content-Type': 'application/json',
    'Idempotency-Key': crypto.randomUUID()
  },
  body: JSON.stringify({
    dest: 'https://store.yourbrand.com/products/summer26',
    title: 'Summer Campaign',
    tags: ['summer', 'promo']
  })
});
const link = await res.json();
console.log('Short URL:', link.shortUrl);
# Python 3 requests
import requests
import uuid

res = requests.post(
    'https://hea.link/api/v1/links',
    headers={
        'Authorization': f'Bearer {API_KEY}',
        'Content-Type': 'application/json',
        'Idempotency-Key': str(uuid.uuid4())
    },
    json={
        'dest': 'https://store.yourbrand.com/products/summer26',
        'title': 'Summer Campaign',
        'tags': ['summer', 'promo']
    }
)
print(res.json()['shortUrl'])

🔑 Authentication & Permissions

The HEA Link API uses secret API keys to authenticate requests. Provide your key in the HTTP Authorization header using the Bearer scheme, or as an X-API-Key header.

Never commit secret API keys to public repositories or expose them in client-side mobile/browser applications.

Key Prefixes & Test Sandbox Mode

Prefix Environment Description
hea_live_... Production Live requests targeting real links, live custom domains, and public click telemetry.
hea_test_... Test Sandbox Isolated test sandbox. Resources created with test keys are marked isTest: true and will never pollute production metrics or real link lists.

Granular API Scopes

Scope Description
links:read List and view short link details, destination URLs, tags, and settings.
links:write Create, update, tag, and delete short links.
analytics:read Retrieve click counts, geo-breakdown, referrer, and device telemetry.
qr:write Generate dynamic vector QR codes (SVG, PNG, Data URIs).
domains:read List registered branded custom domains and DNS verification status.

🔄 Idempotent Requests

The API supports idempotency for POST and PATCH requests to prevent accidental duplicate actions caused by network timeouts or automated retries.

To perform an idempotent request, attach a unique string in the Idempotency-Key header (such as a UUID v4). If a request with the same key is received within 24 hours, the server returns the cached response with the header X-Cache: HIT-Idempotency without re-executing business logic.

⏱️ Rate Limits & Response Headers

API requests are throttled per API key on a 60-second sliding window based on your plan tier:

Plan Tier Rate Limit Burst Allowance
Free 60 requests / minute 10 req / sec
Pro 300 requests / minute 30 req / sec
Enterprise 1,200 requests / minute 100 req / sec

Every API response includes standard HTTP rate limit headers:

  • X-RateLimit-Limit: The maximum number of requests allowed in the current window.
  • X-RateLimit-Remaining: The number of requests remaining in the current window.
  • X-RateLimit-Reset: Unix timestamp (in seconds) when the current window resets.
  • X-Request-Id: Unique trace ID assigned to every request for debugging.

When the rate limit is exceeded, the server responds with HTTP 429 Too Many Requests and a Retry-After header indicating the number of seconds to back off.

📄 Cursor Pagination

List endpoints (like GET /api/v1/links) use cursor-based pagination for high performance and consistent result streaming. Pass limit (default 20, max 100) and cursor query parameters.

GET /api/v1/links?limit=20&cursor=lnk_65e12f90a

{
  "links": [...],
  "pagination": {
    "hasMore": true,
    "nextCursor": "lnk_65e12f90b",
    "total": 142
  }
}

⚠️ Error Handling & Format

All client and server errors return standard JSON envelopes with descriptive codes, human-readable messages, and tracking request IDs:

{
  "error": {
    "code": "INVALID_ARGUMENT",
    "message": "Destination URL must be a valid public http/https address.",
    "details": { "field": "dest" }
  },
  "requestId": "req_89f02b1c4e"
}

📚 Core v1 Endpoints

POST /api/v1/links

Create a shortened URL with optional custom slug, tags, password protection, and expiration date.

Body Parameter Type Description
dest required string Target destination URL (HTTP or HTTPS).
customSlug optional string Custom alphanumeric slug (3-40 chars, hyphens allowed).
title optional string Friendly label for dashboard and reports.
tags optional array<string> Array of tag strings for categorization.
password optional string Passcode required before visitors are redirected.
expiresAt optional ISO-8601 string Timestamp when the link will automatically expire (HTTP 410).
GET /api/v1/links

List links with cursor pagination, tag filtering, and search.

GET /api/v1/links/:slug

Retrieve single link configuration, click count, destination, and creation metadata.

PATCH /api/v1/links/:slug

Update destination URL, title, tags, password protection, or expiration of an existing link.

DELETE /api/v1/links/:slug

Permanently remove a short link and release its custom slug.

GET /api/v1/links/:slug/analytics

Fetch click telemetry, countries, referrer domains, and devices for a single short link.

GET /api/v1/analytics

Fetch account-wide aggregate click telemetry, top performers, and timeline breakdowns.

POST /api/v1/qr

Generate high-resolution vector QR code payload (PNG, SVG, or Data URL) with custom styling.

GET /api/v1/domains

List authenticated branded custom CNAME domains and DNS verification status.

GET /api/v1/me

Validate your API key or token, view account tier, scopes, and sandbox status.
